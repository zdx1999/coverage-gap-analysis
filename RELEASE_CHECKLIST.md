# GitHub release checklist

- [ ] Replace placeholder author information in `CITATION.cff`.
- [ ] Add the manuscript DOI or preprint DOI when available.
- [ ] Confirm the intended software license with all co-authors.
- [ ] Decide whether derived CSV tables in `outputs/tables/` can be public.
- [ ] Do not upload raw Weibo text, user identifiers, or restricted third-party geospatial files.
- [ ] Upload large data files to an approved repository and link the DOI in `README.md`.
- [ ] Test the full workflow after downloading data into `data/`.
- [ ] Confirm figures regenerated from scripts match the submitted manuscript figures.
